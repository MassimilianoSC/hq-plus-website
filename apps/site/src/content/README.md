# Contenuti editoriali

Questa cartella è riservata ai contenuti strutturati gestiti con Astro Content
Collections, quando il sito introdurrà articoli o pagine con uno schema condiviso. La
homepage attuale mantiene i testi vicino alle rispettive sezioni in `components/sections`.
Prima di aggiungere una collection, definire lo schema in `src/content.config.ts`.
